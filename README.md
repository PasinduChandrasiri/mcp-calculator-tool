# 🧮 MCP Calculator Tool

A fast, interactive Multi-Channel Prompt (MCP) server that exposes calculator operations with AI-assisted prompts.  

---

## ✨ Features

- ➕ **Addition**: Add two numbers  
- ➖ **Subtraction**: Subtract two numbers  
- ✖️ **Multiplication**: Multiply two numbers  
- ➗ **Division**: Divide two numbers (with zero division handling)  
- 👋 **Dynamic Greeting Resource**: Personalized greetings  
- 💬 **Styled Prompt**: Generate greetings with friendly, casual, or formal styles  

---

## ⚡ Installation

- git clone https://github.com/PasinduChandrasiri/mcp-calculator-tool
- cd mcp-calculator-tool
- uv add "mcp[cli]"
- uv run server.py


Connect the server in Claude Desktop or any MCP-compatible client.

---

## 💻 Usage

### Example:
- Use add tool with 5 and 7 → Returns 12  
- Use greeting tool with name "Pasindu" → Returns "Hello, Pasindu! 👋"
